# 😷 Face Mask Detection System

## 📌 Project Description
This project detects whether a person is wearing a face mask or not using Deep Learning and Computer Vision. The system runs in real time using webcam input and GPU acceleration.

## 🎯 Objective
To develop an AI-based system that automatically detects masked and unmasked faces.

## 💡 Motivation
During COVID-19, monitoring mask usage became important for public safety. This project automates monitoring using Artificial Intelligence.

## 🧠 Technologies Used
- Python
- OpenCV
- TensorFlow / Keras
- CNN (Convolutional Neural Network)
- GPU Acceleration

## ⚙️ Features
- Real-time face detection
- Mask / No-mask classification
- Fast GPU processing

## ▶️ How to Run
1. Install required libraries
2. Run:
   ```
   python detect_mask.py
   ```
